# Гойдакрафт — сайт сервера

Официальный сайт сервера **Гойдакрафт**, собранный на **Next.js** и разворачиваемый как статический экспорт.  
Проект сделан как атмосферный промо-сайт с упором на индустриальный стиль, модовую сборку, подключение к серверу и страницу доноров.

## Что есть в проекте

- Главная страница с оисание сервера, копированием IP и трейлером.
- Страница модов с полным каталогом сборки, фильтрами и поиском.
- Страница подключения с IP, версией, статусом сервера и ссылками на сообщество.
- Страница доноров с доской почёта.
- Страница газеты с архивом PDF-выпусков, просмотром прямо в браузере и скачиванием.
- Декоративная консоль сервера в виде отдельной страницы.
- 404-страница в едином визуальном стиле.
- Глобальная анимация загрузки, кастомные курсоры, префетч и кеширование через service worker.

## Технологии

- **Next.js 13.4.8**
- **React 18.2**
- **Static export** (`output: 'export'`)
- **Node.js >= 14**

## Маршруты

| Путь | Назначение |
| --- | --- |
| `/` | Главная страница |
| `/mods` | Каталог модов и варианты сборки |
| `/connect` | Инструкция по подключению к серверу |
| `/donors` | Доска почёта доноров |
| `/newspaper` | Архив серверной газеты с PDF-выпусками |
| `404` | Пользовательская страница ошибки маршрута |

## Основные особенности

### Главная

- Кнопка с IP сервера: `goidacraft.aboba.host`
- Копирование адреса в буфер обмена
- Встраиваемый YouTube-трейлер
- Блок «О проекте» с описанием философии сервера
- Быстрые ссылки на ключевые разделы сайта

### Моды

Страница `/mods` содержит:

- каталог модов по категориям;
- поиск по названию;
- карточки с детальным описанием модов;
- два варианта сборки: **GOIDAbase** и **GOIDAslon**;
- два формата установки: **ZIP** и **.mrpack**;
- кнопку загрузки сборки.

Сборка заточена под **Minecraft 1.21.1** и **NeoForge 21.1.228**.

### Подключение

Страница `/connect` показывает:

- IP сервера;
- статус онлайн/офлайн;
- число игроков;
- версию игры и платформу;
- ссылки на Telegram и Discord;
- пошаговую инструкцию подключения.

Статус сервера берётся из внешнего API `mcsrvstat.us`.

### Доноры

Страница `/donors` отображает список поддержавших проект и поясняет, на что идут средства: хостинг, домен и развитие сервера.

### Газета

Страница `/newspaper` содержит архив серверной газеты в PDF-формате:

- список выпусков с переключением между номерами;
- встроенный просмотрщик PDF прямо на странице;
- скачивание выбранного выпуска;
- навигацию по выпускам с клавиатуры.


## Структура проекта

```text
.
├── pages/                 # Страницы и layout-компоненты Next.js
├── assets/styles.css      # Глобальные стили и дизайн-система
├── public/
│   ├── assets/            # JS-скрипты, изображения, курсоры
│   ├── fonts/             # Шрифты проекта
│   └── cache-worker.js    # Service Worker для кеширования
├── out/                   # Результат статической сборки
├── next.config.js         # Конфигурация Next.js
└── package.json           # Скрипты и зависимости
```

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска сайт будет доступен на `http://localhost:3000`.

## Сборка

```bash
npm run build
```

Сборка создаёт статический сайт в папке `out/`.

## Публикация

Проект рассчитан на статическое размещение. После сборки содержимое папки `out/` можно загрузить на любой хостинг статических сайтов.

> В этой конфигурации основной сценарий — именно статическая выдача из `out/`, а не серверный runtime.

## Внешние зависимости

- `https://api.mcsrvstat.us/2/goidacraft.aboba.host` — статус сервера
- jsDelivr — CDN, откуда загружается `manifest.json` и PDF-выпуски газеты
- YouTube — встроенный трейлер на главной
- Telegram / Discord — ссылки сообщества
- Google Drive — ссылка на скачивание модпака

## Дизайн и поведение

- Единая индустриально-паровая тема оформления.
- Кастомные курсоры и декоративные шестерёнки.
- Лоадер на первом входе в сессию.
- Prefetch страниц и ресурсов при наведении на ссылки.
- Service worker для кеширования изображений и части данных.
