Create · Сердце фабрики: шестерни, линии и автоматизация
- Create - Базовый техномод с валами, шестернями, конвейерами и сборочными линиями; фундамент большинства Create-аддонов в сборке.
- Create: Aeronautics - Воздушные и подвижные конструкции на базе Create: дирижабли, летательные платформы и продвинутая кинематика.
- Create Crafts & Additions - Связывает кинетику и электричество: генераторы, моторы, катушки и энергоинфраструктура для фабрик.
- Create: Enchantment Industry - Автоматизация чар и связанных процессов через механизмы Create, включая массовую обработку предметов.
- Create: Central Kitchen - Интеграция кулинарных модов с Create: конвейерная обработка еды, рецепты и кухонная автоматизация.
- Create: Tweaked Controllers - Расширенные контроллеры и более гибкое управление контрапциями, логикой и режимами работы.
- Create: Contraption Terminals - Терминалы/интерфейсы для удалённого управления контрапциями и удобной настройки сложных механизмов.
- CreateBetterFPS - Оптимизационный аддон для Create, снижающий нагрузку от рендера и симуляции крупных механических систем.
- Create: Diesel Generators - Дизельная энергетика для фабрик: генераторы, топливные цепочки и индустриальные энерголинии.
- Create: The Factory Must Grow - Тяжёлая индустрия для Create: расширенные производственные линии, техпроцессы и крупная заводская логистика.

Create · Стальные маршруты и грохот орудий
- Create Big Cannons - Артиллерийская ветка для Create: крупнокалиберные пушки, боеприпасы и баллистика.

- Create: Threaded Trains - Улучшения производительности и обработки поездов/маршрутов в крупных железнодорожных сетях.
- Vista Aeronautics Fix - Исправления совместимости Vista и Create: Aeronautics для стабильной работы камер/визуальных систем на летающих контрапциях.

Архитектура и визуальный стиль базы
- Rechiseled - Огромный набор декоративных вариантов блоков с акцентом на архитектуру и стилизацию построек.

- Stone Zone (Every Compat module) - Расширение совместимости каменных наборов и блоков для строительных модов.
- Sawmill (Universal Sawmill) - Универсальный распил древесины и удобная переработка деревянных блоков.
- Joy of Painting - Художественный мод: краски, холсты/рисование и декоративное оформление баз.
- Exposure - Аналог «фотоаппарата» в Minecraft: съёмка, фотоконтент и атмосферное документирование мира.
- Vista - Камеры, экраны и медиа-элементы (ТВ/трансляции) для охранных систем и интерьерной визуализации.
- AppleWood ReBarked - Декоративная/совместимостная обработка древесины яблони с дополнительными древесными вариантами.

Технический фундамент: библиотеки и API
- Architectury API - Кросс-лоадерный API для разработки модов под разные загрузчики.
- AzureLib - Библиотека анимаций и кастомных моделей (в т.ч. Bedrock-стиля) для модовых сущностей/предметов.

- Curios API - API дополнительных слотов экипировки (кольца, амулеты и пр.) для модовой экипировки.
- Forge Config API Port - Порт Forge Config API для совместимости конфиг-системы на нужном лоадере.
- Kotlin for Forge - Рантайм/инфраструктура Kotlin для модов, написанных на Kotlin.
- Lodestone - Техническая библиотека с общими системами и утилитами для модов авторской экосистемы.
- Moonlight Lib - Библиотека Selene/Moonlight: регистры, datapack-утилиты, вспомогательные API и совместимость.
- Rhino - JS-движок/библиотека, используемая модами вроде KubeJS для исполнения скриптов.
- Sable - Библиотека интерактивных подвижных структур и «саб-уровней» для сложной механики.
- Sophisticated Core - Базовая библиотека для линейки Sophisticated-модов.
- SuperMartijn642's Config Lib - Утилитарная библиотека конфигов для модов SuperMartijn642 и совместимых проектов.
- SuperMartijn642's Core Lib - Базовое ядро/общие классы для модов SuperMartijn642.
- Ritchie's Projectile Library - Библиотека для систем снарядов и баллистической логики в зависимых модах.
